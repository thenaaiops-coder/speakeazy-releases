# Speakeazy

Hold a key, talk, let go: clean text in your own voice appears wherever you type. Everything runs on your Mac.

**[Download Speakeazy 0.5.0 for Mac](https://github.com/thenaaiops-coder/speakeazy-releases/releases/download/v0.5.0/Speakeazy-0.5.0.dmg)** (macOS 14 or later, Apple Silicon)

1. Open the file and drag Speakeazy onto Applications.
2. Open Speakeazy. If macOS says it "could not verify" it, click Done, then go to System Settings > Privacy & Security and click **Open Anyway**. You only do this once: later updates install from inside the app.
3. Allow Microphone and Accessibility when asked. Hold Right Option and talk.

## What's new in 0.5.0

- **Updates from inside the app** (Mac): Speakeazy checks for new versions and installs them with one click, then restarts. No more downloading and dragging, and no more "Open Anyway" after the first install
- **Permissions survive updates** (Mac): releases are signed with one Speakeazy certificate, so Accessibility and Microphone stay allowed
- **Easier first install** (Mac): the download has a "Read me first" note, and there's a public download page to share
- Robot animation redone: every movement is a spring, eyes stretch with your voice, the head leans in, blinks ease, and moods blend into each other instead of cutting (Mac, Windows, iPhone)
