# Speakeazy

Hold a key, talk, let go: clean text in your own voice appears wherever you type. Everything runs on your Mac.

**[Download Speakeazy 0.5.2 for Mac](https://github.com/thenaaiops-coder/speakeazy-releases/releases/download/v0.5.2/Speakeazy-0.5.2.dmg)** (macOS 14 or later, Apple Silicon)

1. Open the file and drag Speakeazy onto Applications.
2. Open Speakeazy. If macOS says it "could not verify" it, click Done, then go to System Settings > Privacy & Security and click **Open Anyway**. You only do this once: later updates install from inside the app.
3. Allow Microphone and Accessibility when asked. Hold Right Option and talk.

## What's new in 0.5.2
